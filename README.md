# Correlation Between Runtime and Ratings Across Genres in Popular Anime
The repository contains analysis on whether the runtime of an anime is related to its rating and whether this relationship differs across genres. 

The analysis uses data obtained from AniList through a Kaggle dataset and focuses on popular anime entries, defined as the top 50% by popularity. Runtime, genre, popularity, and user ratings were analyzed using Bayesian-style weighted ratings and Spearman's correlation coefficient.

## Structure of the Analysis and Requirements
### Analysis Workflow
- Initial data selection in Microsoft Excel
- Data processing in C++ 
- Visualization and Spearman correlation in Python

### Required Python libraries

The required libraries can be installed using:

`pip install pandas matplotlib scipy numpy`

## Data sample
The original dataset can be acquired using this link: 
[AniList Anime Dataset](https://www.kaggle.com/datasets/calebmwelsh/anilist-anime-dataset)

The dataset used in the analysis was obtained on September 13, 2026, and originally contained 20,425 entries. 
Initial selection was performed in Excel, reducing the dataset to 17,419 entries. 

That entailed:
- Removing entries with missing values in the variables required for the analysis
- Retaining only anime with a finished status
- Calculating the season runtime of each entry as: runtime = episodes × duration
- Replacing commas with hyphens
- Removing quotation marks, line breaks, and square brackets

The cleaned dataset can be found in the `dataset/` directory.

### Directory Description
- `data_analysis/` contains the analysis code.
- `data_analysis/python_files/` contains intermediate CSV files generated by the analysis.
- `analysis.cpp` performs the main data processing and analysis.
- `visualization.py` generates the figures and calculates Spearman's correlation coefficients.
- `dataset/` contains the AniList dataset after initial selection and the original dataset description.
- `figures/` contains the visualizations used in the report.
- `report/` contains the LaTeX source code and the final report PDF.

## Running the Analysis
To reproduce the results:

1. Use the cleaned dataset located in `dataset/anilist_anime_data.csv`.
2. Run `analysis.cpp` to:
   - classify anime by genre and runtime category
   - apply the popularity cutoff
   - calculate Bayesian-style weighted ratings
   - perform genre-runtime aggregation
   - calculate uncertainty on mean Bayesian ratings
   - generate the intermediate CSV files
3. Run `visualization.py` to:
   - generate the figures used in the report
   - calculate Spearman's correlation coefficients

The generated visualizations are saved in the `figures/` directory.
